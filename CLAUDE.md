# Project Context

## Tech Stack
- Next.js 16 with App Router
- Cloudflare Workers (via OpenNext)
- Cloudflare D1 (SQLite) — database (replaced Supabase; see docs/adr/0005)
- Better Auth (email+password) on D1 — auth (see docs/adr/0006)
- Resend for email
- next-intl for i18n (de/en)

## Deployment

## Environment Variables

Defined in `wrangler.jsonc` under `vars`:
- `NEXT_PUBLIC_BASE_URL` - base URL for email links
- `BETTER_AUTH_URL` - base URL for Better Auth

Secrets (set via `wrangler secret put`):
- `RESEND_API_KEY`
- `BETTER_AUTH_SECRET`

Bindings (`wrangler.jsonc` → `d1_databases`):
- `DB` - the Cloudflare D1 database (`custix-db`)

## Database (Cloudflare D1)

Migrations in `migrations/`. Schema designed in `docs/schema/d1-licensing-schema.md`.
- Better Auth tables (`user`/`session`/`account`/`verification`) — generated by `@better-auth/cli`, migration 0001
- `person` — PII vault (name/email/profession); GDPR erasure anonymizes here (ADR-0008)
- `waitlist_entry` — beta requests (replaces old `signups`)
- `license` — the single entitlement the desktop app validates (ADR-0002)
- `admin_role` — who can use the admin panel
- `admin_event` — audit trail of admin actions
- `license_event` — funnel/telemetry (replaces old `download_events`)

See `docs/SETUP-PHASE1.md` for D1 create / migrate / secret steps (cloud resources you set up).

## Key Features (Phase 1 — beta access)

- Beta waitlist capture (signup modal → `/api/signup`, no auto-download during beta)
- Admin panel (`/admin`) — approve→mint+email key, revoke, reset claim, anonymize
- License validate (`/api/license/validate`) + claim (`/api/license/claim`) — desktop app contract
- Phase 2 (deferred): Stripe subscriptions (card monthly/annual; invoice annual-only)
